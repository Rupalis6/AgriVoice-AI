AGRIVOICE AI - READY-TO-RUN PROJECT

1. Open the AgriVoice_AI_Ready folder.
2. Open the .env file in Notepad.
3. Replace PASTE_YOUR_GROQ_API_KEY_HERE with your real Groq API key. Save.
   Do not share the .env file or upload it to GitHub.
4. Double-click RUN_AGRIVOICE.bat. First run installs required packages and may take a few minutes.
5. Streamlit opens in your browser.

If the browser does not open, wait for the terminal and open the local URL it prints (usually http://localhost:8501).

Features: multilingual English/Hindi/Marathi AI responses via Groq, predefined agriculture context, text-to-speech.
Prototype limitations: no live weather, live mandi feed, voice-to-text, or full document RAG.
